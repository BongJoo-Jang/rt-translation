# BJ 통역 — 웹앱 (iPhone · iPad · PC 공용)

- **위 창 (상대방, 영어 → 한국어)**: ‘듣기 시작’을 누르면 마이크로 상대방의 영어를 듣고 한국어 자막을 실시간으로 보여줍니다.
- **아래 창 (나, 한국어 → 영어)**: 한국어를 입력하고 잠시 멈추면(또는 ↑ / Enter) 영어로 크게 보여줍니다.
  - ↩ 뒤집기: 영어 결과를 180° 돌려 마주 앉은 상대가 바로 읽게 함
  - ⤢ 크게 보기: 화면 가득 크게 (탭하면 닫힘)
  - 🔊 읽어주기: 영어를 소리 내어 읽음 (읽는 동안 마이크 자동 무음)
- **⏺ 녹음**: 듣는 동안 오디오를 이 기기에 녹음 (네트워크 전송 없음). 끝나면 **녹음 저장** → iPhone은 ‘파일에 저장’
- **공유 버튼(오른쪽 위)**: 상대방·내 발언 기록을 .txt로 공유·저장

파일 7개(`index.html`, `manifest.webmanifest`, 아이콘 PNG 4개, `README.md`)로 이루어진 정적 웹페이지이며, 서버가 필요 없습니다.

## 1. GitHub Pages에 올리기 (처음 한 번, 약 5분)
마이크는 **HTTPS 주소**에서만 쓸 수 있어서, 무료 HTTPS 호스팅인 GitHub Pages에 올립니다.

1. github.com에서 **New repository** → 이름 예: `bj-translate` → **Public** → Create
   (Private 저장소에서 Pages를 쓰려면 유료 플랜이 필요합니다. 공개돼도 API 키는 코드에 없으니 안전합니다.)
2. 저장소 화면에서 **Add file → Upload files** → 압축을 푼 파일 7개를 끌어다 놓기 → **Commit changes**
3. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main** / **(root)** → Save
4. 1~2분 뒤 같은 화면에 주소가 표시됩니다: `https://<GitHub아이디>.github.io/bj-translate/`

수정할 때는 바뀐 파일만 같은 방법으로 다시 올리면 1~2분 뒤 모든 기기에 반영됩니다.
(git을 쓰신다면 `git push`로 올려도 됩니다.)

## 2. iPhone · iPad에 설치
1. **Safari**로 위 주소를 엽니다.
2. 공유 버튼 → **홈 화면에 추가** → 추가. 홈 화면에 BJ 아이콘이 생기고, 앱처럼 전체 화면으로 열립니다.
3. 처음 열면 설정 창이 뜹니다. **OpenAI API 키**를 붙여넣고 **키 저장** → 완료.
   - 키는 그 기기의 그 브라우저(홈 화면 앱)에만 저장되고, OpenAI로만 전송됩니다. 기기마다 한 번씩 입력하세요.
   - OpenAI 대시보드에서 `web-interpreter` 같은 이름으로 키를 따로 만들면 사용량 구분과 폐기가 쉽습니다.
4. **듣기 시작** → 마이크 권한 **허용**.

PC(Chrome·Edge)에서도 같은 주소로 열어 쓸 수 있습니다.

## 3. 사용 요령
- 통역 중에는 화면이 꺼지지 않게 설정됩니다. **다른 앱으로 넘어가거나 화면을 끄면 듣기가 멈춥니다**(iOS 웹앱 제약). 돌아오면 다시 ‘듣기 시작’을 누르세요.
- 내 한국어 말은 위 창에 표시되지 않습니다(설정에서 끌 수 있음). 내가 영어로 길게 말할 때는 ⏸ 일시정지.
- 키보드의 🎤 받아쓰기로 한국어를 말로 입력할 수 있습니다. 듣기 중에는 마이크가 겹쳐 끊길 수 있으니 잠시 일시정지 후 받아쓰세요.
- iOS는 마이크를 쓰는 동안 스피커 소리가 작아질 수 있습니다. 🔊 읽어주기 소리가 작으면 볼륨을 올리거나 이어폰을 쓰세요.
- 설정 → **회의 설명**에 주제·참석자·전문용어를 적으면 한→영 번역에 반영됩니다.

## 4. 오디오 녹음
1. **듣기 시작** 후 **⏺ 녹음**을 누르면 빨간색 ‘녹음 중 00:00’으로 바뀝니다.
2. 다시 누르거나 **정지**를 누르면 녹음이 끝나고 **녹음 저장** 버튼이 나타납니다.
3. **녹음 저장** → iPhone·iPad는 공유 화면에서 **파일에 저장**(또는 AirDrop으로 PC에 전송), PC는 다운로드 폴더에 저장됩니다.
- 파일 형식: iPhone·iPad는 .m4a, PC(Chrome·Edge)는 .webm. 1시간에 약 20 MB.
- 일시정지·읽어주기 중에도 녹음은 계속됩니다.
- **저장 버튼을 누르기 전에 앱을 닫으면 녹음이 사라집니다.** 녹음은 메모리에만 있다가 저장할 때 파일이 됩니다.
- 회의 녹음은 참석자에게 미리 알리고 동의를 받으세요.

## 6. 문제 해결
| 증상 | 해결 |
|---|---|
| "HTTPS 주소에서 열어야…" | 파일을 직접 열지 말고 GitHub Pages 주소로 여세요. |
| "마이크 권한이 필요합니다" | iPhone 설정 → Safari → 마이크 → 허용 (또는 주소창 ‘가가’ → 웹사이트 설정). |
| 영어 원문이 안 나오고 상태에 "원문 전사 없이 연결" | 설정 → 모델 → 원문 전사 모델 이름을 확인하거나 비워 두세요. 번역은 정상 동작합니다. |
| "연결 실패" / "API 오류" | API 키, OpenAI 크레딧 잔액, 월 사용 한도를 확인하세요. 모델 이름 오류면 설정 → 모델에서 수정. |
| 브라우저에서 OpenAI 연결 자체가 막힘(네트워크/CORS 오류) | 회사망 차단일 수 있습니다. 휴대폰 데이터로 시도해 보고, 계속 안 되면 키를 대신 보관하는 작은 중계 서버(Cloudflare Worker)를 붙이면 됩니다. |

## 보안 메모
- 이 페이지는 **개인용**입니다. 주소가 공개돼 있어도 API 키는 각 기기에만 있으므로 다른 사람이 열어도 내 키는 쓸 수 없습니다(그 사람이 자기 키를 넣으면 자기 비용으로 쓰는 구조).
- 공용 PC에서는 사용 후 설정 → **삭제**로 키를 지우세요.
